# ANCIT-HACKATHON – Embedded Systems

## Project Overview
This project demonstrates two approaches to input detection in embedded systems: Polling and Interrupt-Based Input Detection.

Developed as part of the ANCIT Mega Hackathon.

## Programming Language
- Embedded C

## Concepts Used
- GPIO configuration
- Digital input and output
- Polling mechanism
- Interrupt handling
- Interrupt Service Routine (ISR)
- LED and switch interfacing

## Working Principle

### 1. Polling
The microcontroller continuously checks the switch state and responds when an input is detected.

### 2. Interrupt-Based Detection
The microcontroller responds to an interrupt event using an Interrupt Service Routine instead of continuously checking the input.

## Project Objectives
- Understand polling and interrupt mechanisms.
- Compare two input detection approaches.
- Explore embedded firmware development.
